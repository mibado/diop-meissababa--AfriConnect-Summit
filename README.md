# 🌍 AfriConnect Summit 2026

![AfriConnect Summit]

## 📌 Présentation du projet

**AfriConnect Summit 2026** est un site web vitrine moderne conçu pour présenter une conférence tech panafricaine fictive réunissant développeurs, entrepreneurs, investisseurs et passionnés d'innovation.

L'objectif du projet est de proposer une expérience utilisateur complète avec :
- une interface moderne inspirée des sites événementiels internationaux ;
- un design responsive adapté aux mobiles, tablettes et ordinateurs ;
- un mode sombre/clair ;
- des animations fluides ;
- des interactions dynamiques en JavaScript vanilla.

Ce projet a été réalisé dans le cadre d'un projet académique en développement web.
